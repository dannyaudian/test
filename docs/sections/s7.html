Technology and Control Enablers

System components that carry out input ownership, validation, and carry-forward of data.

SAM — Single front-end

Used by the Frontman to:

  • Input customer and transaction data.
  • Upload documents.
  • Create payment requests.
  • View open unit bills.
  • Monitor payments and receipts.
  • Submit Sales Order request.
  • Request billing.
  • Request AFI/DO.
  • Request delivery.
  • Submit handover evidence.
  • Monitor STNK/BPKB.
  • View failed compliance rules.
  • Complete missing requirements.
  • Submit eligible compliance exception.
  • View exception decision and escalation.

  • Receipt generation and posting.
  • Outstanding balance.

Integration and API Layer

  • Connects SAM, SAP/ERP, Banking API, Document Vault, Compliance Exception Approval Engine, and the customer channel.
  • Prevents re-input.
  • Synchronizes status.
  • Maintains SPK–SO–Billing lineage.
  • Enriches receipt lineage when the SO or billing is issued.
  • Triggers downstream processes.

Compliance Exception Approval Engine

  • Failed compliance gate only.
  • Waivable versus non-waivable classification.
  • Role-based decision authority.
  • Evidence completeness.
  • Approve with conditions.
  • Reject.
  • Return for completion.
  • Validity period and expiry.
  • Limited release by process, unit, and Sales Order.
  • Automatic re-lock.
  • SLA monitoring and escalation.

Transaction value, discount, cashback, program, and OPO/OPK remain read-only source-system data and are not approval objects within FAST.

Document Vault

  • Store documents once.
  • Validate document status.
  • Reuse valid documents.
  • Support AFI/DO, delivery, STNK, and BPKB.
  • Store digital handover evidence (photo, VIN, geotag, timestamp, recipient, BSTKB) as one pack.
  • Give the same pack to Frontman, Administration, and the customer after Good Issue is approved.
  • Prevent repeated document upload.

B2B Leasing Integration

  • Per-SO status from submit to leasing through settlement.
  • Frontman downloads the leasing-submitted contract, re-uploads the customer-signed contract, and uploads signed-contract photo, handover photo, and BSTKB.
  • Frontman also uploads documents leasing requested (identity, NPWP, NIB/SIUP, SPK).
  • Administration sends paperless billing and issues the leasing receipt only after that Frontman pack is complete and full customer DP from B2B is paid.
  • Normal flow and backflow on the same tracker when leasing or Administration returns incomplete documents.
  • Required customer DP amount and DP-received status come from B2B leasing (read-only in FAST) and appear on the Sales Order pricing structure when payment type is credit/leasing.
  • Billing gate reads full-DP status; delivery gate reads TTD status. Neither is an Approval Engine object.
  • Missing documents are operational backflow, not a waiver of DP or TTD.
  • Contract date and reference.
  • Read-only commercial facts into FAST gates; Frontman still performs the human upload/download steps.

E-Receipt Service

  • Generate one receipt per verified payment.
