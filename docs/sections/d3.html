D3

Deliverable 3 — Documents, pajak, dan logistik STNK/BPKB

Upload sekali ke Document Vault, validasi, lalu pakai again dari SPK sampai AFI, serah terima, STNK, dan BPKB. Administration memeriksa, bukan mengupload again paket yang same.

What changes

The document gate opens the booking fee billing request — not SO directly. Missing or expired items go back to the input owner. Only waivable document rules enter Approval Engine.

Features

Document Vault

KTP, NPWP, KK, PO, NIB, akta, documents leasing, STNK, pajak, surat kuasa, BSTKB, OKK elektronik disimpan sekali. Pemakaian berikutnya membaca vault, bukan folder branch terpisah.

Example in the mockup Upload di SPK Dewi. Pakai again di vault Budi — KTP/NPWP dari Customer ID yang same.

Kelengkapan dan masa berlaku

Sistem menandai missing/expired sebelum langkah keuangan atau AFI. Frontman melengkapi; Administration memverifikasi. Repeat order memakai documents yang masih valid.

Example in the mockup Sarah NPWP missing: #tx_raize — lengkapi di SPK, fee not yet ditagih. Address Budi expired: #exc_alamat (waivable, Admin tidak upload again).

Data STNK ikut ke AFI

STNK name, address, and reserved/issued license plate are pulled from SPK. Billing and AFI are submitted as a pair; breaking the sequence is an exception (D1/D4), not the norm.

Example in the mockup AFI Budi #afi sudah terisi dari SPK. Pecah urutan hanya di #exc_afi.

Tracking STNK/BPKB

Status, aging, dan eskalasi operasional (bukan waiver komersial) terlihat di workspace unit. Hari ke-n dan blocker tampil di jejak transactions itu sendiri.

Example in the mockup Maria Fortuner hari ke-19: #tx_fortuner · eskalasi KC #exc_stnk — bukan button paid in full.

Handover Proof digital

Unit photos, geotag, BSTKB, and the proof package go into the vault. Good Issue uses the same evidence, not a separate paper form that gets retyped.

Example in the mockup Fajar GI #gi. Customer Calya download paket yang same di #bukti_serah — bukan CCTV dealer.

Pajak dan matching

Monitor tax documents and vehicle–document matching in Administration. Mismatches hold the process or enter exception flow if the policy is waivable.

Example in the mockup Matching terlihat di antrean Administration, bukan folder terpisah di menu Frontman.

Flow in the mockup

Upload di SPK→Vault + cek berlaku→Booking fee boleh ditagih→Pakai again AFI/DO→Proof GI→STNK/BPKB
