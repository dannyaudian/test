D3

Deliverable 3 — Documents, tax, and STNK/BPKB logistics

Upload once to the Document Vault, validate, then reuse from SPK through AFI, handover, STNK, and BPKB. Administration reviews rather than re-uploading the same package.

What changes

The document gate opens the booking fee billing request — not SO directly. Missing or expired items go back to the input owner. Only waivable document rules enter Approval Engine.

Features

Document Vault

KTP, NPWP, KK, PO, NIB, deeds, leasing documents, STNK, tax, power of attorney, BSTKB, electronic OKK are stored once. Subsequent use reads the vault, not a separate branch folder.

Example in the mockup Upload in SPK Dewi. Reuse in Budi's vault — KTP/NPWP from the same Customer ID.

Completeness and validity period

The system flags missing/expired items before financial steps or AFI. Frontman completes them; Administration verifies. Repeat orders use documents that are still valid.

Example in the mockup Sarah NPWP missing: #tx_raize — complete it in the SPK, the fee is not yet billed. Budi's address expired: #exc_alamat (waivable, Admin does not re-upload).

STNK data carries into AFI

STNK name, address, and reserved/issued license plate are pulled from SPK. Billing and AFI are submitted as a pair; breaking the sequence is an exception (D1/D4), not the norm.

Example in the mockup AFI Budi #afi is already filled from SPK. Breaking the sequence only through #exc_afi.

STNK/BPKB tracking

Status, aging, and operational escalation (not a commercial waiver) are visible in the unit workspace. Day n and blockers appear in the transaction's own trail.

Example in the mockup Maria Fortuner day 19: #tx_fortuner · KC escalation #exc_stnk — not a paid-in-full button.

Handover Proof digital

Unit photos, geotag, BSTKB, and the proof package go into the vault. Good Issue uses the same evidence, not a separate paper form that gets retyped.

Example in the mockup Fajar GI #gi. Customer Calya downloads the same package at #bukti_serah — not dealer CCTV.

Tax and matching

Monitor tax documents and vehicle–document matching in Administration. Mismatches hold the process or enter exception flow if the policy is waivable.

Example in the mockup Matching is visible in the Administration queue, not a separate folder in the Frontman menu.

Flow in the mockup

Upload in SPK→Vault + validity check→Booking fee can be billed→Reuse AFI/DO→GI proof→STNK/BPKB
